# 개인 업무 커맨드센터

이번 주 일정, 진행 중인 과제, 다가오는 마감을 한 화면에서 보는 개인용 대시보드입니다.
`index.html` 파일 하나로 동작하고, 인터넷 연결 없이도 열립니다.

- 웹에서 열기: https://shin-changhee.github.io/mydashboard/
- 내 PC에서 열기: `index.html`을 내려받아 더블클릭 (Chrome, Edge)

## 화면 구성

| 영역 | 내용 |
|---|---|
| 상단 바 | 날짜, 시계, **지금 한눈에**(지금·다음 일정, 오늘 할 일, 급한 마감, 다가오는 쉬는 날), 퇴근 카운트다운과 오늘 근무 진행률 (공휴일·연차에는 그날 이름 표시) |
| 이번 주 타임라인 | 월~일 일정. 빈 칸을 누르면 추가, 블록을 누르면 수정·삭제. 매주 반복(종료일, 이번 주만 빼기) 지원. 표시 시간 밖 일정은 요일 옆 ↑↓ 표시 |
| 다가오는 마감 | D-day 표시 (D-3 이내 빨강, D-7 이내 주황). 지난 마감·완료 마감은 접어서 보관 |
| 오늘 할 일 3가지 | 하루 3개까지만. 날짜가 바뀌면 새 목록 |
| 진행 중인 과제 | 진행률 10% 단위 조절, 상태별 필터 |
| 바로가기 · 설정 · 백업 | 자주 쓰는 사이트, 근무 시간·카테고리·쉬는 날(연차 등) 설정, JSON 내보내기/가져오기, 자동 보관본 되살리기 |
| **루틴** (상단 '루틴' 메뉴) | 루틴 추가·삭제·순서 변경, 날짜별 체크 표(Week 1~5), 오늘까지 달성률·완료·남음·오늘, 주별·일일 달성률 차트, 루틴별 분석 |
| **식단** (상단 '식단' 메뉴) | 아침·점심·저녁에 먹은 음식 기록(쉼표로 여러 개, 전에 적은 음식 자동 완성), '안 먹음' 표시, 날짜 이동, 이번 주 식단표(월~일) |

## 구글 캘린더 연동 (인터넷 PC 전용, 선택)

설정에서 켜면 구글 캘린더 일정을 타임라인에 함께 보여줍니다(읽기 전용, 저장 안 함).
웹 주소로 열었을 때만 동작하며, 꺼 두면 외부와 전혀 통신하지 않습니다.
준비 방법은 [GOOGLE_SETUP.md](GOOGLE_SETUP.md)를 보세요.

## 클라우드 동기화 (선택)

구글 계정으로 로그인하면 Firebase(Firestore, 서울 리전)에 저장해서 집 PC·회사 인터넷 PC·휴대폰에서 같은 대시보드를 봅니다.
내 계정만 읽고 쓸 수 있게 보안 규칙([firestore.rules](firestore.rules))으로 막습니다.
업무망 PC는 화면 아래 ☁ 버튼에서 "이 기기는 클라우드를 쓰지 않음"을 켜 두세요.
준비 방법은 [FIREBASE_SETUP.md](FIREBASE_SETUP.md)를 보세요.

## 휴대폰에서

- 이번 주 타임라인은 제목 옆 **접기/펼치기**로 접을 수 있어요. 휴대폰에서는 처음에 접힌 상태로 시작하고, 기기마다 따로 기억해요.
- 펼치면 휴대폰 폭에서는 타임라인을 하루씩 보여줍니다. 요일 버튼을 누르거나 좌우로 밀어서 넘기세요.
- 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 아이콘으로 열 수 있고, 인터넷이 끊겨도 열립니다.

## 데이터 저장

- 데이터는 **지금 쓰는 브라우저 안(localStorage)** 에 먼저 저장됩니다. 클라우드에 로그인하지 않으면 외부 서버로 보내지 않습니다.
- 웹 주소로 연 화면과 파일을 더블클릭해서 연 화면은 저장 공간이 서로 다릅니다.
  옮기려면 한쪽에서 **백업 → 백업 파일 내려받기**, 다른 쪽에서 **백업 → 가져오기**를 하세요.
- 브라우저 기록(사이트 데이터)을 지우면 대시보드 데이터도 지워지니, 가끔 백업 파일을 받아 두세요.
- 일정 제목과 링크 정도만 넣고, 개인정보나 내부 문서 내용은 넣지 마세요.
