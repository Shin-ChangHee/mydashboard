    쉬는 날 (연차·임시공휴일 등)

    법정 공휴일(2025~2028년)은 자동으로 표시돼요. 연차나 새로 정해진 임시공휴일은 여기에 넣으면 퇴근 카운트다운 대신 그날 이름이 보이고, 타임라인 요일에도 표시돼요.

    샘플 데이터

    처음에 넣어 둔 예시 일정·과제·마감·바로가기를 지워요. 직접 고친 항목은 남겨 둬요.

    대시보드에는 일정 제목과 링크 정도만 넣어 주세요. 개인정보나 내부 문서 내용은 넣지 않는 것을 전제로 만들었어요. 데이터는 먼저 이 브라우저 안에 저장돼요. 클라우드 동기화(☁)에 로그인하면 내 구글 계정의 Firebase 저장소(서울)에도 저장되고, 로그인하지 않거나 "이 기기는 클라우드를 쓰지 않음"을 켜면 외부로 보내지 않아요. 구글 캘린더 연동은 일정을 읽어 오기만 하고, 대시보드 데이터를 보내지 않아요. 업무 일정을 외부 클라우드에 저장해도 되는지는 기관의 보안 지침을 확인해 주세요.
